# Игорь Янчуков

## Внедрение AI и автоматизация

Работаю на стыке управленческой задачи, системной логики и AI-assisted delivery. Определяю требуемое поведение, направляю итерации coding agents, проверяю результат и принимаю решения о дальнейших изменениях.

Я не позиционирую себя как классического программиста. Репозитории показывают возможности проектов; они не являются доказательством ручного написания кода или экспертного владения каждым стеком.

### Проекты

- [DirectorIQ](directoriq.md): управленческий workflow, HTTP API, PostgreSQL, сводки через Ollama.
- [DirectorIQ Local AI Node](directoriq-local-ai-node.md): концепция локального помощника руководителя на административных данных.
- [VitaCRM](vitacrm.md): обработка поручения через черновик и человеческое подтверждение.
- [LegasVex](legasvex.md): проект с API, локальной моделью, orchestration и approval-компонентами; без заявления готового RAG/MCP или production-системы.

### Для пилотов

Начинать с одной управленческой задачи, одного разрешённого источника и измеримых критериев приёмки. Для медицинской организации начальный scope — только административные данные. Медицинские данные пациентов не предполагаются.

Профиль посвящён проектам и способу работы. Личные контакты не публикуются.
