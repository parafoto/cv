# VitaCRM

**Проект:** локальный CRM/workflow прототип.  
**Статус:** API, SQLite, задачи, обработка поручений, AI adapters и подтверждение черновика присутствуют в исходном коде. Исторический smoke report не подтверждает текущую доступность приложения.

## Подтверждённый сценарий проекта

Текстовое или голосовое поручение разбирается в черновик. Пользователь может подтвердить или отменить черновик; подтверждённый вариант становится задачей. В проекте есть HTTP JSON API, SQLite storage, Ollama/optional provider/rules fallback и журнал событий.

## Моя функция

Я задаю требуемый сценарий и бизнес-логику, направляю AI-assisted итерации и проверяю поведение. Код проекта не следует трактовать как доказательство, что я вручную написал его или самостоятельно реализовал каждый adapter.

## Ограничения

Это не подтверждённая production CRM, не медицинская система и не интеграция с МЕДСИ. Текущий runtime не запущен; внешний Telegram transport и credentials не проверялись. RAG, MCP и автономный AI-агент не подтверждены.
