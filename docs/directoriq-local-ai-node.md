# DirectorIQ Local AI Node

**Статус: PRODUCT CONCEPT.** Описанная архитектура не внедрена в МЕДСИ или другую медицинскую организацию.

## Идея

Локальный или on-premise AI-контур для руководителя, который работает только с разрешёнными ему административными и управленческими данными.

Mac mini — один возможный reference node для демонстрационного пилота. Продукт не привязан к Apple или конкретной аппаратной платформе.

```text
Разрешённые административные источники
        ↓
Контролируемый слой интеграций
        ↓
Локальный узел руководителя
        ↓
LLM и поиск по знаниям с указанием источников
        ↓
DirectorIQ: SEE → подготовка действия → подтверждение
        ↓
Evidence Pack и журнал решения
        ↓
Решение человека
```

## Возможные сценарии

- ежедневная управленческая сводка;
- список поручений и событий, требующих внимания;
- подготовка к совещаниям;
- поиск по разрешённым внутренним документам;
- проект действия с подтверждением руководителя;
- объяснение вывода через использованные источники и выдержки.

## Текущая доказательная граница

В DirectorIQ есть задачи, напоминания, сводки и код вызова Ollama. Локальный Ollama daemon на этой машине отвечал на API проверки моделей, но модель не была загружена и генерация не проверялась. Отдельный локальный orchestrator реализован в коде, однако текущий runtime не подтверждён.

Не подтверждены как готовые компоненты концепции: управляемое подключение корпоративных источников, RAG, Evidence Pack, proactive prevention и явный approval gate для AI-предложений. Audit log DirectorIQ не следует называть Evidence Pack.

## Минимальный демонстрационный сценарий

Одна утренняя сводка по синтетическим или отдельно разрешённым административным данным; ссылки на использованные записи; проект поручения без исполнения до подтверждения; журнал решения и безопасный отказ при отсутствии источника или модели. Медицинские данные пациентов в начальный scope не входят.

Реальный пилот требует отдельной проверки источника данных, прав доступа, хранения, сетевых границ, журналирования и безопасности. Нормативное соответствие заранее не заявляется.
