# DirectorIQ

**Проект:** локальная управленческая CRM и workflow задач.  
**Статус:** функциональные части реализованы в исходном коде; исторические тестовые отчёты существуют. Текущий runtime не подтверждён.

## Возможности, подтверждённые в проекте

- HTTP API на Fastify и PostgreSQL/Drizzle schema.
- Задачи, обещания, напоминания и журнал событий.
- Сводка по карточке и утренний брифинг с вызовом Ollama и rule-based fallback.
- Правила обнаружения уже просроченных задач и обещаний.
- Код OAuth/API для Google Calendar; хранение токенов в production не завершено.

## Моя функция

Я определяю требуемую бизнес-логику и направление изменений, ставлю задачи AI coding agents, веду итерации и проверяю результат. Это описание способа delivery, а не утверждение, что я вручную написал каждый модуль.

## Границы

- Вызов Ollama есть в коде; актуальная end-to-end генерация не проверена.
- Текущая конфигурация Docker Compose не включает Ollama; сетевое подключение контейнера к локальному daemon надо отдельно настроить и проверить.
- Анализ просроченных элементов не является доказательством предиктивного предотвращения.
- Audit log не равен Evidence Pack с цитируемыми источниками.
- RAG, MCP и отдельное подтверждение AI-рекомендации не подтверждены.
- Нет интеграции с МЕДСИ, МИС или ЭМК.

## Роль в DirectorIQ Local AI Node

DirectorIQ может стать оболочкой задач, сводок и действий для демонстрации концепции. Он пока не образует готовый локальный AI-контур: авторизованные корпоративные источники, документный RAG, Evidence Pack и цикл одобрения AI-действия не соединены в продукт.
