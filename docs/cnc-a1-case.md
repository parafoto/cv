# CNC-A1: AI-assisted operations brief

**Прикладной кейс:** автоматизация управленческой сводки по заявкам сайта и локальной CRM.  
**Публичный сайт:** [cnc-a1.ru](https://cnc-a1.ru/) отвечает по HTTPS.  
**Статус AI-сценария:** MCP tool code реализован; протокол и сводка проверены на временной синтетической SQLite-базе. Работа подключённого Codex MCP на фактическом runtime и чтение рабочей CRM не подтверждены.

## Какой сценарий автоматизируется

Вместо ручного просмотра всей воронки руководитель может запросить краткий срез:

- сколько заявок поступило за выбранный период и сегодня;
- сколько заявок остаётся открытыми;
- как они распределены по статусам;
- сколько новых или ожидающих уточнения заявок;
- сколько открытых заявок просрочены по сроку.

Codex может использовать только эти агрегаты для короткого операционного брифа и подсказок о том, что проверить. Выводы ограничены измеримыми счётчиками; инструмент не позволяет выводить клиентов, выручку, конверсию или прогнозы.

## Проверенные границы кода

- MCP tool: `get_cnc_a1_sales_brief`.
- Источник: локальная D1-compatible SQLite база заявок.
- Подключение задаётся в read-only режиме; для соединения выполняется `PRAGMA query_only=ON`.
- Инструмент возвращает только количества и статусы; не выбирает имена, контакты, описания, файлы, суммы или идентификаторы.
- Нет инструментов изменения CRM, отправки писем или сообщений.
- Сценарии follow-up готовятся только из заметок, предоставленных пользователем; отправка и запись в CRM не выполняются.

## Текущая проверка

На синтетической временной базе прошли MCP `initialize`, `tools/list` и `tools/call` для `get_cnc_a1_sales_brief`. Полученные тестовые количества совпали с fixture; поля с синтетическими именами, email, заметками и суммами в ответ не попали.

Этот тест проверяет протокол и фильтрацию ответа самого сервера. Он **не** подтверждает:

- загрузку инструмента в Codex на рабочем устройстве;
- соединение с актуальной локальной CRM CNC-A1;
- актуальность и качество данных CRM;
- работу AI-агента end-to-end на реальной воронке;
- наличие AI-функции на публичном сайте cnc-a1.ru.

Рабочая CRM-база в этом аудите не открывалась. Публичный сайт CNC-A1 и локальная CRM/MCP-автоматизация — отдельные контуры. Проектная политика требует локального размещения; CRM и её данные нельзя публиковать или переносить в публичную среду.

## Безопасный сценарий демонстрации

1. Показать публичный сайт CNC-A1 как рабочий канал заявок.
2. Показать на синтетических или заранее обезличенных данных, как запрос сводки вызывает локальный MCP tool.
3. Показать, что ответ содержит только агрегаты, а AI формирует короткий бриф с разделением фактов и рекомендаций.
4. Показать, что система не пишет в CRM и не отправляет сообщения.

Для демонстрации реальных показателей требуется отдельно проверить Codex/MCP runtime и согласовать объём данных, который допустимо показывать. Не открывать клиентские записи или коммерческие показатели на встрече без явного разрешения.
